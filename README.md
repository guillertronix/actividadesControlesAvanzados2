Actividad GitHub Pages

En esta actividad se ha utilizado uno de los repositorios de GitHub del módulo para crear una nueva rama llamada gh-pages.

Primero se ha creado la rama gh-pages a partir de la rama main del repositorio. Después, se ha cambiado a esta nueva rama y se ha eliminado el contenido que había anteriormente.

A continuación, se ha creado este archivo README.md, donde se explica el proceso realizado en la actividad.

Por último, se ha habilitado GitHub Pages para que utilice la rama gh-pages y se ha comprobado que el contenido del repositorio se puede visualizar correctamente mediante la URL proporcionada por GitHub.
